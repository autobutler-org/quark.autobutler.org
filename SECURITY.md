# Security Policy

This repository is the static marketing site for
[Quark](https://github.com/autobutler-org/quark). It has no backend, no
database, and no accounts. Vulnerabilities in the Quark product itself belong
in the [product repository](https://github.com/autobutler-org/quark/security/advisories/new),
not here.

## Supported Versions

Only what is currently deployed at <https://quark.autobutler.org> is supported.
The site is rebuilt and republished from `main` on every merge, so fixes ship
as soon as they land. There are no maintained release branches.

## Reporting a Vulnerability

For anything exploitable — a supply-chain compromise in a dependency, a way to
inject content into the published page, a misconfigured Pages deployment —
**file a private advisory**, not a public issue:

<https://github.com/autobutler-org/quark.autobutler.org/security/advisories/new>

Please include what you found, how to reproduce it, and what an attacker could
do with it. We will acknowledge the report and let you know what we intend to do
about it.

Do not open a public issue or a pull request that demonstrates the problem
before we have had a chance to respond.

## Out of scope

- Missing security headers that GitHub Pages does not let us set
- Reports generated by an automated scanner with no demonstrated impact
- Anything requiring a compromised browser, extension, or machine

## Our commitments

The site collects nothing. It has no analytics, no tag manager, no session
recording, no tracking pixels, and no third-party embeds, and it loads no
scripts, fonts, or stylesheets from other origins. If you find something on the
published page that contradicts that, treat it as a security issue and report it
the same way.
