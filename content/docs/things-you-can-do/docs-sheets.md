# Write docs & sheets

**Goal:** open a document or spreadsheet in the browser, with the file living on
your Quark drive — not on someone else’s servers.

> **Soft launch:** Docs and Sheets work for everyday writing and light
> spreadsheet work. Expect rough edges. Fancy templates, offline-first editing
> everywhere, and full Google Docs / Excel parity are **not** promised in this
> release.

## You will need

- Quark reachable on your home WiFi
- A signed-in account
- A modern desktop or laptop browser (phone editing is usable for short notes,
  less comfortable for long docs)

## Start a document

1. Open Quark and sign in.
2. Open **Documents** (or Docs) from the app.
3. Create a new document, or open one you already saved.
4. Write as you normally would. The file sits on your drive the whole time.

<!-- screenshot TBD: new document editor -->

## Start a spreadsheet

1. Open **Spreadsheets** (or Sheets) from the app.
2. Create a new sheet, or open an existing one.
3. Enter numbers, lists, or a simple budget. Same idea: the file is on your
   hardware.

<!-- screenshot TBD: new spreadsheet -->

## Where the files live

Docs and sheets are ordinary files on the storage Quark manages. You can also
find them through [Work with files](/docs/things-you-can-do/files) if you need to
move, rename, or download a copy.

## Honest limits (soft launch)

- Best on home WiFi for now — remote access from outside the house is still
  coming later
- Collaboration features (many people editing one doc at once from anywhere) are
  not the focus of this release
- Do not expect every Google Docs or Excel feature yet
