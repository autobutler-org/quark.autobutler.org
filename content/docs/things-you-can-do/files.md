# Work with files

**Goal:** find, upload, and tidy files on the drive attached to Quark — from any
device on your home WiFi.

## You will need

- Quark powered on and reachable on your home network
- A phone or computer on the same WiFi
- (Recommended) a USB drive or external hard drive attached to Quark

<!-- screenshot TBD: Cirrus file browser home -->

## Open the file browser

1. Open Quark in a browser (or the phone app) while on home WiFi.
2. Sign in.
3. Open **Files** (sometimes labeled **Cirrus** in the app) — that is the file
   browser.

<!-- screenshot TBD: Files / Cirrus entry in the app drawer -->

## Browse folders

When you open Files you will see your folders listed. You can:

- **Click a folder** to open it
- **Click a file** to download or preview it (images and common types open in a
  viewer)
- **Use the breadcrumb bar** at the top to navigate back up
- **Click the home icon** in the breadcrumb to jump back to the root

### Changing the view

Files has three layouts — pick whichever works best:

- **List** — compact rows, good for lots of files
- **Grid** — larger thumbnails, good for photos
- **Unified / Per-device** — see all storage as one view, or each drive
  separately

### Searching for a file

Click the search icon in the top bar and type a filename. Quark searches across
connected storage.

## Upload files

1. Navigate to the folder you want.
2. Click **Upload** in the top bar.
3. Choose files from your device.
4. Wait for the progress indicator to finish.

You can upload several files at once. Large files may take a moment on home
WiFi.

<!-- screenshot TBD: Upload button and progress -->

## Create a folder

1. Navigate to where you want the new folder.
2. Click **New** in the top bar.
3. Type a name and confirm.

## Move, rename, and delete

Right-click (or long-press on mobile) any file or folder for the action menu:

- **Rename** — change the name
- **Move** — move it to a different folder or drive
- **Delete** — send it to Trash

### Trash

Deleted items go to **Trash** (open it from the app drawer). Each row shows
where the item came from and how many days are left before Quark removes it for
good.

From Trash you can:

- **Restore** — put it back (if something new already sits at that path, move or
  rename the new thing first; restore will not overwrite)
- **Delete permanently** — remove it now, with a confirm step
- **Empty trash** — clear everything shown (also confirms)

Items stay recoverable for about **30 days**, then an automatic sweep deletes
them. Treat that window as a change-your-mind period, not long-term storage.

## More than one drive

If Quark has more than one storage device attached:

- Use **Unified** view to see everything in one place
- Use **Per-device** view to see each drive separately
- When uploading, you may be asked which device to use
